# Groove City College: multiplayer campus map

A Cloudflare Worker that serves the walkable Groove City College map and lets everyone who opens it walk around together. Each visitor gets a random name (for example `SwiftOtter42`) when they enter, and their position and heading are shared live with everyone else on the map. There is one shared campus room, with up to 40 visitors at once.

## Files

| File | What it is |
| --- | --- |
| `src/worker.js` | The Worker (serves the page and `/ws`) and the `MapRoom` Durable Object that relays positions |
| `src/page.html` | The built map page. Generated by `npm run build`; do not edit it by hand |
| `wrangler.jsonc` | Worker configuration (Durable Object binding, page import rule) |
| `build.mjs` | Rebuilds the page from `../src/template.html` and `../tools/data.js` |
| `package.json` | Build and deploy scripts, and the Wrangler version |

## Run it locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:8787. Open a second window to see a second visitor.

The build step runs Python (`../src/assemble.py`). It uses `python` by default. On macOS or Linux, if that command is missing, set `PYTHON=python3`, for example `PYTHON=python3 npm run dev`.

## Deploy

```sh
npx wrangler login     # once, to sign in to your Cloudflare account
npm run deploy         # rebuilds the page, then publishes the Worker
```

Wrangler prints the public URL when it finishes, in the form `https://groove-city-college.<your-subdomain>.workers.dev`. Use `npx wrangler deploy` alone only if `src/page.html` is already up to date.

## Making changes

- **Visitor cap:** `MAX_PLAYERS` in `src/worker.js` (currently 40). Every position update is sent to every visitor, so keep this modest.
- **Random names:** the `ADJECTIVES` and `NOUNS` lists in `src/worker.js`.
- **Map, walking and look:** edit `src/template.html` in the project's `src` folder, then run `npm run build`. The multiplayer code is in the section headed `multiplayer` in that file.
- **Update rate:** each browser sends at most about 8 position updates a second, and the Worker ignores updates arriving faster than `MIN_MOVE_MS` (60 ms).
- **Map bounds:** `BOUNDS` in `src/worker.js` clamps positions to the campus. It is centred on 0,0, like the page's coordinates.

## How it works

1. A visitor clicks **ENTER CAMPUS**. The page opens a WebSocket to `/ws`.
2. The Worker sends the connection to one Durable Object named `campus`, which holds the room.
3. The room gives the visitor an id and a random name, and sends a `welcome` message listing the visitors who have a position.
4. The room announces the newcomer with `join`. The newcomer's avatar appears once their first position arrives.
5. Each visitor sends `{t: 'move', x, y, z, yaw}`. The room clamps the values and relays them to everyone else as `move`.
6. When a visitor disconnects, the room sends `leave`. If the connection drops, the page retries up to five times, with increasing delays.

Positions are not saved. The room is empty when the last visitor leaves, and nobody keeps their name between visits.

## Limits and things to know

- **No accounts, chat or moderation.** Anyone who can reach the URL can join and appears with a random name.
- **Positions are not checked against the map.** Each browser moves its own visitor, so someone can walk through walls in their own copy. The Worker only checks that values are numbers within the campus bounds.
- **Background people are not shared.** The walkers heading to Breen and Hicks run in each browser separately, and they still use the browser's built-in text-to-speech.
- **One room.** It suits dozens of visitors at once. It is not designed for hundreds.
- **Cost.** Cloudflare bills Durable Object requests and WebSocket messages. Check current pricing before you share the link widely.
- **Artifact preview.** Claude's artifact preview cannot open the WebSocket, so the map runs there as single-player.
- **Map data.** `../tools/data.js` is a copy of the output of `../tools/build.py`. Rebuilding it needs the source downloads (satellite, elevation and OpenStreetMap data), which are not in this folder.
